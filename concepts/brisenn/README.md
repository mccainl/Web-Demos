# BRISÉNN — MCC concept

Public concept on GitHub Pages: https://mccainl.github.io/Web-Demos/brisenn/

The 20-second 720p Kling film retains its original scenes and uses an edited contemporary electronic soundtrack. Background music is opt-in with a dedicated sound control. All interface symbols are inline SVG, including on iOS.

Scroll assembly uses a 96-frame WebP sequence with a bounded decode cache, independent of mobile video seeking. The full video remains available as a tap-to-play alternative.

The composition atelier uses a physical 3D acrylic viewer, individual colour/finish controls, a vertical full-piece view, original product photographs and a size calculator. Material studies are illustrative; the actual product photographs are available from each selected material. Room placement uses photograph-relative geometry, with optional measured scale and local-only uploads.

The product detail dialog includes photographs, dimensions, finish information, hook pricing and a link to the original store. This concept does not run checkout.

Validation: GitHub Actions runs the complete experience in desktop Chromium and mobile WebKit, including frame pixel changes, sound playback, material changes, product details, size calculation and room export.

MCC concepts must be published on GitHub Pages, not OpenAI Sites. Product photography belongs to BRISÉNN. Interior and material studies are concept visualisations.

## Tactile atelier update
The studio now uses locally bundled Three.js with bevelled, open acrylic geometry, physical transmission, a softbox environment, drag/touch orbit, pinch/button zoom and a reset view. Every numbered link has independent colour/finish. Full-piece and detail views share one validated composition state with the room preview, calculator, save and share. Product photography remains available for final material reference. Rendering pauses outside the viewport.
