# BRISÉNN — MCC concept

Public interactive concept hosted on GitHub Pages. Product photography belongs to BRISÉNN; generated interior and film frames are concept imagery. No checkout or live store administration is connected.

Features: interactive acrylic chain composition, colour and finish selection, size calculator, photo placement with optional calibration, share links and downloadable composition. Geometry and room placement are approximate visual studies.

The accompanying film is a 20-second introduction to handmade acrylic wall art, showing links connecting and the chain in a refined living room. Kling 4.0, 720p concept output.

## MCC deployment preference

Publish MCC concepts through GitHub Pages. Do not deploy MCC concepts to OpenAI Sites. Give clients a public webpage they can open and interact with.
